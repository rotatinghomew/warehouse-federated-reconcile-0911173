# 地区报送约定

来源声明full表示其明确覆盖范围内的完整业务键清册，delta仅描述本次变化。当前单文件入口的覆盖范围固定为整个地区；学校子范围材料不应伪装成这种全地区full。新增分片协议中，源端清单可声明覆盖学校集合、报送序号、全部片标识与摘要，空集合和缺少范围声明不等同。

完整空清册只删除声明范围内已存在的业务键；未闭合清单中的缺失不能推导删除。delta的delete有明确业务键，与传输文件里缺少一行不同。序号由地区源端给定，不由到达时间生成；报送替代关系由来源明确声明，未声明的冲突不能凭文件名覆盖。

文件摘要对应实际内容而非文件名，补交片需要指向原批次。declared_rows用于核对传输条目，入仓净变化与参与人数不同，不能要求这三种数机械相等。核对需要保留从来源声明到仓层键、汇总及公开发布的关系。
